> A lightweight, standalone web application inspired by the famous **McBroken** website. It allows you to see and track where things are working or broken around the world in real-time.

Unlike complex projects that require servers, Node.js setups, or databases, this repository contains a **single autonomous file**. You just need to download it and open it in Google Chrome!

---

## 🚀 Key Features

- 🗺️ **Interactive World Map:** Visualizes real-time global positions using free, open-source cartography from **Leaflet.js** and **OpenStreetMap**.
- 🟢🔴 **McBroken Style Indicators:** Dynamic colored map markers displaying whether a location's service is operational (green) or broken (red).
- 📊 **Live Failure Statistics:** Instantly calculates the global percentage of broken machines right in the application header.
- ⚡ **Zero Installation:** Powered entirely by cloud CDNs (React, Tailwind CSS, and Leaflet load dynamically on launch).

---

## 🔧 How to Run It Instantly

You don't need to run any terminal commands or install software. Follow these simple steps:

1. **Download the file:** Click on the `index.html` file inside this repository and download it to your computer.
2. **Open it:** Double-click the downloaded `index.html` file, or right-click it and select **Open with > Google Chrome**.
3. **Enjoy!** The interactive map will render right away with mock real-time tracking indicators.

---

## 🛠️ Built With

- **React.js (v18)** - Component rendering and live state management directly in the browser via Babel.
- **Tailwind CSS (v4)** - Clean, modern, responsive interface styling for the header metrics and dashboard panels.
- **Leaflet.js** & **OpenStreetMap** - Interactive mapping engine running beautifully without premium Google Maps API keys.
